# MenuCycle

MenubarX처럼 메뉴바에서 웹페이지를 띄우는 macOS 앱. 여러 페이지를 단축키로 순환할 수 있음.

## 설치 / 업데이트

**처음 한 번만** 터미널에서:
```bash
xcode-select --install                          # 개발 도구 (이미 있으면 생략)
bash ~/Downloads/MenuCycle/업데이트.command
```
→ 설치되고, 바탕화면에 **MenuCycle 업데이트** 아이콘이 생깁니다.

**다음부터는** 새 MenuCycle.zip을 받은 뒤 바탕화면의 **MenuCycle 업데이트**를 더블클릭하면 끝.
(다운로드 폴더에서 가장 최근에 받은 MenuCycle zip이나 폴더를 알아서 찾아 빌드·설치합니다. 압축을 풀 필요도, 예전 폴더를 지울 필요도 없음)

## 기본 단축키 (설정에서 전부 변경 가능)

| 동작 | 기본 키 |
|---|---|
| 열기 / 닫기 | `⌃⌥M` |
| 다음 / 이전 페이지 | `⌃⌥]` / `⌃⌥[` |
| N번 페이지 | `⌘1` ~ `⌘9` |
| 주소창 | `⌘L` |
| 뒤로 / 앞으로 / 새로고침 | `⌘[` / `⌘]` / `⌘R` |
| 창 닫기 | `Esc`, 바깥 클릭 (각각 켜고 끌 수 있음) |
| 탭 닫기 / 닫은 탭 다시 열기 | `⌘W` / `⌘⇧T` (마지막 탭에서 ⌘W는 창 닫기) |
| 새 탭 | `⌘T` |
| 페이지에서 찾기 / 다음 / 이전 | `⌘F` / `⌘G` / `⌘⇧G` |
| 확대 / 축소 / 원래 크기 | `⌘+` / `⌘-` / `⌘0` |
| 현재 탭 음소거 | `⌘⇧M` |
| 영상 PIP | `⌘⇧P` |
| 설정 | `⌘,` 또는 주소창 오른쪽 ⚙︎ 또는 메뉴바 아이콘 우클릭 |
| 항상 위에 표시 · 다른 곳 클릭 시 닫기 | 메뉴바 아이콘 우클릭 또는 설정 |

## 설정 창

- **일반**: 로그인 시 자동 실행, 마지막 페이지 기억, 검색 엔진(Google/네이버/DuckDuckGo), 새 창 링크 처리
- **단축키·닫기**: 단축키 녹화, "열기와 닫기를 같은 키로" 체크박스(끄면 닫기 키를 따로 지정하고, 열린 상태에서 열기 키를 누를 때 '다음 페이지'로 갈지 '아무것도 안 할지' 선택), 다음/이전 페이지 키, 바깥 클릭·Esc·⌘W로 닫기
- **창**: 위치(메뉴바 아래 / 화면 가운데 / 마지막으로 옮긴 위치), 크기, 탭 막대·주소창·전환 표시, 항상 위, 모든 데스크탑에서 표시
- **페이지**: 추가·삭제·이름·주소·모바일 화면 여부, 드래그로 순서 변경

## 탭

- 탭을 클릭하면 해당 페이지로, 좌우로 끌면 순서 변경, 우클릭 → 탭 닫기
- 오른쪽 `+` (또는 `⌘T`)로 새 탭. 새 탭은 Google로 열리고, 이름·주소가 보고 있는 사이트를 따라감

## 주소창

- 주소를 입력하면 해당 페이지로 이동하고, 검색어를 입력하면 설정한 검색 엔진으로 검색합니다
- 🏠 이 페이지의 기본 주소로 돌아가기
- 🔊 현재 탭 음소거
- 🖥 화면 종류: PC / iPhone / iPad / Android / 직접 입력한 User-Agent
- ⋯ 더 보기: PIP, 찾기, 확대/축소, 자동 새로고침(1~60분), 창 닫으면 영상·음악 일시정지 켜기/끄기, 다운로드 폴더 열기

## 그 밖에

- 파일 다운로드 → 다운로드 폴더에 저장 (같은 이름이 있으면 `이름 (2)`로)
- 영상 전체화면 버튼 동작
- 설정 → 일반: 안 본 탭을 N분 뒤 메모리에서 내리기, 창 닫을 때 영상·음악 일시정지
- 설정 → 창: 창 투명도

설정 파일은 `~/Library/Application Support/MenuCycle/config.json`에 있으며, 이전 버전의 설정은 자동으로 옮겨집니다.
